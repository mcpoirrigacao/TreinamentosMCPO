# Treinamentos MCPO

Controle de treinamentos corporativos (funcionários) e capacitações de clientes — padrão dos apps internos MAQCAMPO.

- Login Microsoft (mesmo registro de app do Azure dos demais apps MCPO)
- Dados no SharePoint: `Documentos Compartilhados › TreinamentosMCPO` (`treinamentos_dados.json` e `treinamentos_acesso.json`)
- Este repositório não contém dados reais — a base é importada pelo próprio app (⚙ Parâmetros › Importar planilha).
